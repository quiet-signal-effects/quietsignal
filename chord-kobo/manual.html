コード譜クイック工房 使い方

コード譜を素早く入力して、A4の1ページに印刷・PDF保存するためのアプリの説明書です。スマホでもPCでも同じように使えます。

はじめに：ファイルの構成

  • index.html … アプリ本体です。この index.html を開いて使います。
  • manual.html … この説明書です（アプリの「？」ボタンからも開けます）。
  • manual.txt … 同じ内容の文章だけの版です。
  • ほかのファイル（sw.js、manifest.webmanifest、icons、vendor）は、アプリが自動で使うものです。開かず、そのまま置いておいてください。
  • 説明書だけを開いても、アプリは動きません。必ず index.html（またはそのアドレス）を開いてください。

1. このアプリでできること

  • コードをキーパッドで素早く入力する
  • 1行の小節数を4・6・8、または1〜9小節から自由に決める
  • 1小節を2つ、または4つに分けて、コードを入れる
  • セクション名（Intro、A、B、サビなど）と繰り返し記号を付ける
  • 色・大きさ・フォントを選んでテキストを入れる
  • 戻す・やり直し、移調、段のコピー・切り取り・貼り付け
  • A4の1ページに収めて、印刷またはPDFで保存する
  • 譜面をファイルに保存して、あとで読み込む

2. 画面の見かた

画面は大きく3つに分かれます。

  1. 上のバー: 使い方（？）、戻す・やり直し、小節数、段数、新規、⚙（移調・ファイル）、PDF、印刷のボタンがあります。
  2. 譜面: 白いA4の紙の形をした部分です。ここに書いたものが、そのまま印刷されます。
  3. 下の入力パネル: コードを入力するキーパッドや、各種の操作ボタンがあります。パネルの左上の「▼ 閉じる」で小さくでき、「▲ 入力パネルを開く」で戻せます。

上のバーに入りきらないときは、左右にスクロールできます。

3. はじめての入力（5ステップ）

  1. 譜面の一番上にある「タイトル」「アーティスト名」「Key / テンポ」の欄に、曲の情報を入力します。
  2. 最初の小節をタップします。選んだ小節は、青く表示されます。
  3. 下のキーパッドで、コードを入力します。たとえば C → m → 7 とタップすると、Cm7 になります。
  4. 「次へ ▶」を押すか、次のコードのルート（C〜B）をタップします。次の小節に進みます。
  5. 入力し終わったら、上のバーの「PDF」または 🖨 で保存・印刷します。

4. コードの入力

キーパッド

段 キー
ルート C D E F G A B
基本 ♭ ♯ m 7 M7 m7 dim aug sus4
追加 add9 6 9 m7♭5 sus2 7sus4 dim7 m9 M9
テンションなど ♭5 ♯5 ♭9 ♯9 ( ) / % N.C.
  • ⌫ は1文字消します。「消去」は、その枠のコードをすべて消します。
  • PCでは、キーボードで直接入力もできます。♭と♯は、キーボードの b と # で入力できます。

次の小節へ進む方法

  • 「次へ ▶」ボタン、またはPCの Enter / Space / Tab で、次の枠に進みます。
  • 次のコードのルート（C〜B）をタップすると、いま入力中のコードを確定して、自動で次へ進みます。「C → m7 → G → 7」と、続けてタップしていけます。
  • 入力済みのコードを選んでからルートをタップすると、次へ進まず、その場のコードが書き換わります。
  • 「%」をタップすると、その枠が % になり、次へ進みます。入力済みのコードの上でも % に置き換わります。
  • 直前が「/」のとき（オンコードの入力中）は、ルートをタップしても進まず、ベース音として入ります。
  • 「◀」ボタン、PCの Shift+Tab、または空欄での Backspace で、前の枠に戻ります。
  • 一番最後の小節まで進むと、新しい段が自動で足されます（25段まで）。

表記のルール

  • ルート（C、D、Eなど）は大きく、♯・♭はその真横に表示されます。
  • 7、m、M7、add9、sus4、dim などは、小さい文字で右に付きます。下の端は、ルートと揃います。
  • 7(b9) や m7b5 の b と # は、自動で ♭ と ♯ になります。
  • C/E のようなオンコードは、スラッシュとベース音が小さく付きます。
  • N.C.（ノーコード）や %（前の小節と同じ）も入力できます。

5. 小節の操作

1小節を分ける

小節を選び、下のパネルの「この小節の分割」で 1 / 2 / 4 を選びます。

  • 2: 小節を左右に分けて、2つのコードを入れます。
  • 4: 2×2に分けて、4つのコードを入れます。特別な使い方に便利です。

小節数を変える

  • 全体の基本の小節数: 上のバーの「小節数」で、4・6・8のボタン、または数字（1〜9）を入力します。いまその数になっている段が、まとめて変わります。
  • 1段だけ変える: その段の小節を選び、下のパネルの「小節」の右にある数字欄（1〜9）に入力します。「−」「＋」ボタンで1小節ずつ増減もできます。「−」は、選んでいる小節が消えます。
  • 文字の大きさは、上のバーの基本の小節数で決まります。1段だけ多くすると、その段は窮屈になります。

6. 段の操作

段数を変える

上のバーの「段」の数字欄に、10〜25を入力します。段数に合わせて、段の高さが自動で変わり、必ずA4の1ページに収まります。段数が多いほど、文字は小さくなります。10〜16段くらいが見やすい目安です。

段のコピー・切り取り・貼り付け

下のパネルの上にある「行」のボタンで操作します。

  • コピー: 選んでいる段を複製して覚えます。
  • 切取: 段をコピーして、その段を消します。
  • 貼付: 選んでいる段に、覚えた段をその場で貼り付けます（選んでいた段は置き換わります。「戻す」で元に戻せます）。

セクション名や繰り返し記号を含む、段の内容がまるごと複製されます。

行の追加・削除・移動

下のパネルの「セクション・繰り返し・行の操作」をタップして開くと、次のボタンがあります。

  • ＋コード行 / ＋テキスト行: 選んでいる段のすぐ下に追加します。
  • ↑ / ↓: 段を上下に動かします。
  • 行削除: 選んでいる段を削除します。

7. セクション名と繰り返し記号

セクション名

「セクション・繰り返し・行の操作」の中で、段にセクション名を付けます。

  • Intro / A / B / C / サビ / 間奏 / solo / Outro のボタンがあります。
  • 「自由入力」で、好きな名前も付けられます。「解除」で消せます。
  • 譜面に表示されたセクション名をタップしても、名前を直せます。

繰り返し記号（目に付く場所のボタン）

下のパネルの「繰り返し」の行にあります。小節を選んで押すと付き、もう一度押すと外れます。

ボタン 意味 PCのショートカット
‖: 繰り返し開始 Alt + [
:‖ 繰り返し終了 Alt + ]
1. 1番かっこ Alt + 1
2. 2番かっこ Alt + 2
解除 記号をすべて外す Alt + 0

コードを入力している途中でも、ショートカットを使えます。

そのほかの記号（折りたたみの中）

「セクション・繰り返し・行の操作」の中の「この小節に」にあります。

  • D.C. / D.S. / Fine: 小節の下に表示されます。
  • Coda / To Coda: 小節の上に表示されます。
  • 縦二重線: 小節の右端に二重の縦線を付けます。
  • 小節なし（二重取消線）: 小節に二重の横線を引いて、その小節はナシ、という表示にします。

段の繰り返し（×2など）

同じ場所にある「段の繰り返し」で、×2 / ×3 / ×4 を付けます。段の右端の下に表示されます。「自由入力」で別の文字、「解除」で消せます。譜面の「×2」をタップしても、直せます。

8. テキスト行

「＋テキスト行」で、文字だけの段を足せます。譜面のテキストをタップすると、下のパネルで編集できます。

  • サイズ: 小・中・大・特大
  • フォント: ゴシック・明朝・丸ゴ・手書き風・等幅
  • 色: 7色から選べます。
  • 配置: 左・中央・右
  • 太字: チェックを入れると太くなります。

テキスト行は、1段ぶんの高さに収まるように表示されます。長い文章は、2行に分けてください。

9. 戻す・やり直し

  • 上のバーの ↶（戻す） と ↷（やり直し） を使います。
  • PCでは、入力欄の外で Ctrl+Z（戻す）と Ctrl+Y または Ctrl+Shift+Z（やり直し）も使えます。
  • 段の削除、小節数の変更、移調、ファイルの読み込み、「新規」なども、戻せます。

10. 移調

上のバーの ⚙ を押して、「移調」を使います。

  1. 「−」「＋」か数字で、半音の数（−11〜＋11）を決めます。
  2. 「♯で表記」または「♭で表記」を選びます。
  3. 「移調する」を押します。

全部のコードが、同じ数だけ変わります。オンコードのベース音も一緒に変わります。「Key=C」のように書いたキーの欄も、一緒に変わります。曲の調に合わせた自動判定はないので、♯か♭かは、その曲に合うほうを選んでください。

11. 保存・読み込み・新規

ファイルに保存する

⚙ を押して「ファイルに保存」を押すと、譜面全体が「曲名 - アーティスト名.json」というファイルになります。バックアップや、別の端末への引き継ぎに使えます。

ファイルを読み込む

⚙ の「ファイルを読み込む」で、保存したファイルを選びます。いまの譜面が置き換わるので、確認が出ます。読み込んだあとでも、「戻す」で元に戻せます。

新規

上のバーの「新規」で、白紙の譜面から始められます。確認が出ます。

自動保存

入力した内容は、使っている端末のブラウザに、自動で保存されます。ただし、ブラウザのデータを消したり、端末を替えたりすると消えます。大事な譜面は、必ず「ファイルに保存」でバックアップしてください。

12. 印刷とPDF

PDFで保存

上のバーの PDF を押すと、A4の1ページのPDFを作ります。保存の確認が出ます。スマホでは、共有メニューが開くことがあります。PDFは画像なので、文字を選んだりコピーしたりはできません。

印刷

上のバーの 🖨 を押して、ブラウザの印刷画面を開きます。

  • 用紙は A4、向きは縦にします。
  • 倍率は、100%（または初期設定）にしてください。
  • 操作ボタンは印刷されず、譜面だけが出ます。
  • 印刷画面で「PDFに保存」を選ぶと、文字を選べるPDFにもできます。

14. ホーム画面に追加して使う（PWA版）

PWA版は、アプリのようにアイコンから開け、電波がなくても使えます。

  • iPhone（Safari）: 共有ボタン → 「ホーム画面に追加」
  • Android（Chrome）: メニュー → 「アプリをインストール」または「ホーム画面に追加」
  • PC（Chrome / Edge）: アドレスバー右の「インストール」アイコン

最初の1回は、電波のある場所で開いてください。 そのときに必要なファイルが端末に保存されます。この説明書も、一緒に保存されます。

15. よくある質問・困ったとき

入力したのに印刷されない 譜面は、画面の白い部分がそのまま印刷されます。入力欄の中の文字は、「次へ」を押すか、別の場所をタップして確定してください。

文字が小さくなった 段数が多い、または1行の小節数が多いと、1ページに収めるために、文字は小さくなります。段数を減らすか、小節数を減らしてください。

セクション名や記号が見づらい セクション名や、1.2.、D.S. などを付けた段が多いと、その分、ほかの段が小さくなります。必要なところだけに付けてください。

譜面が消えた ブラウザのデータを消したり、端末を替えたりすると、消えることがあります。「ファイルに保存」したファイルがあれば、⚙ の「ファイルを読み込む」で復元できます。

パネルが邪魔で譜面が見づらい 下の入力パネルの「▼ 閉じる」で、パネルを小さくできます。

PDFが作れない うまくいかないときは、🖨 の印刷画面で「PDFに保存」を試してください。

移調したら、♯と♭が思ったのと違う 移調の画面で、「♯で表記」と「♭で表記」を切り替えて、もう一度やってください。「戻す」で、移調前に戻せます。
