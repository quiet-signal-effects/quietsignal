# コード譜クイック工房（PWA版）公開手順

このフォルダの中身をそのまま GitHub Pages に置くと、スマホ・PCで使えて、
ホーム画面に追加でき、電波がなくても動くアプリになります。

## フォルダの中身
- `index.html` … アプリ本体
- `manual.html` … 使い方の説明書（アプリ上部の「？」ボタンからも開けます。オフラインでも読めます）
- `manual.txt` … 同じ内容の文章だけの版（メモ帳などで読めます）
- `manifest.webmanifest` … アプリの名前・アイコンなどの設定
- `sw.js` … オフラインで動かすための仕組み
- `icons/` … アイコン画像（4枚）
- `vendor/` … PDF書き出し用の部品（ネットなしでも動くよう同梱）

### ファイル名について（なぜ「index.html」なのか）
アプリ本体のファイル名は `index.html` のままにしてください。Webサーバー（GitHub Pagesなど）は、
フォルダのアドレスを開かれたとき、`index.html` という名前のファイルを自動で表示する決まりになっています。
名前を変えると、`https://…/chord-kobo/` だけでは開けず、`https://…/chord-kobo/変えた名前.html` と
ファイル名まで入力しないと開けなくなります（ホーム画面のアイコンや、リンクも同様です）。

アプリの名前は、ファイル名ではなく次の場所に「コード譜クイック工房」と書いてあります。
- ブラウザのタブに出る名前（`index.html` の中のタイトル）
- ホーム画面に追加したときの名前（`manifest.webmanifest`。アイコンの下は「クイック工房」）
- ダウンロードしたZIPの名前、展開してできる `chord-kobo` フォルダ

**アプリ本体は `index.html` です。使うときは、この `index.html`（またはそのアドレス）を開きます。説明書だけ開いてもアプリは動きません。**

## 1. GitHub に置く（無料）
1. GitHub にログインし、右上の「＋」→「New repository」を押します。
2. Repository name に好きな名前（例: `chord-kobo`）を入れ、**Public** を選んで「Create repository」。
3. 作成された画面の「uploading an existing file」をクリックします。
4. このフォルダの**中身をすべて**（`index.html`、`manifest.webmanifest`、`sw.js`、`icons` フォルダ、`vendor` フォルダ）をドラッグしてアップロードし、「Commit changes」を押します。
   - フォルダごとドラッグすれば、中のファイルも一緒に上がります。
   - ZIPのままアップロードしても動きません。必ず展開してから上げてください。
5. リポジトリの「Settings」→ 左メニュー「Pages」を開きます。
6. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を **main** / **(root)** にして「Save」。
7. 1〜2分待つと、次のアドレスで開けるようになります。
   `https://【GitHubのアカウント名】.github.io/【リポジトリ名】/`

## すでにあるホームページの中に置く場合
`index.html` などをまとめた**フォルダごと**、ホームページのフォルダの中に置いてください（例: `chord-kobo/`）。
- 開くアドレスは `https://あなたのサイト/chord-kobo/` になります。
- ファイルは、フォルダの中に直接（`chord-kobo/index.html` の形で）置きます。1階層深くしないでください。
- ホームページの `index.html` などは、書き換えません。そこから `chord-kobo/` へのリンクを張れば使えます。
- サイトが https:// で開けることが必要です（GitHub Pages は自動で https です）。

## 2. ホーム画面に追加する
- **iPhone（Safari）**: 開いたあと、下の共有ボタン → 「ホーム画面に追加」。
- **Android（Chrome）**: 右上のメニュー → 「アプリをインストール」または「ホーム画面に追加」。
- **PC（Chrome / Edge）**: アドレスバー右の「インストール」アイコンを押す。

追加後は、アイコンから全画面のアプリとして開き、電波がなくても使えます。
**必ず一度、電波のある場所で開いて**ください（そのとき必要なファイルが端末に保存されます）。

## 3. 更新するとき
このアプリは「版を上げたときだけ」更新されます。
1. `index.html` などを新しいものに差し替えてアップロードします。
2. `sw.js` の `VERSION = 'kobo-v5'`（いまの数字）を `'kobo-v6'` のように**必ず変えます**（変えないと、端末は古い版のままです）。
3. 電波のある場所でアプリを開くと、新しい版が端末に保存されます。反映は、一度閉じて開き直したときからです。

ふだんの起動では、アプリのファイルをサーバーから取りに行きません。
（ブラウザが更新の有無を調べるために、`sw.js`（約1KB）だけは、電波があるとき確認に行きます。）

## 注意
- 譜面のデータは、使っている端末・ブラウザの中に保存されます。ブラウザの閲覧データを消したり、端末を替えたりすると消えます。
  大事な譜面は、⚙ボタンの「ファイルに保存」でバックアップしてください。
- 保存した `.json` ファイルは、別の端末の「ファイルを読み込む」で開けます（Claude上のページで作った譜面も読み込めます）。
- Claude上のページ（リンク版）に保存した譜面は、この版とは別の場所に保存されます。引き継ぐときは、ファイル保存→読み込みを使ってください。
- iPhoneのSafariは、長期間（約7日）開かないサイトのデータを消すことがあります。ホーム画面に追加して使えば、この対象になりにくくなります。
