中心周波数の計算式

LC回路の基本式

f0 = 12π√LC

L：インダクタンス（H）、C：静電容量（F）、f0：共振周波数（Hz）

疑似インダクタ回路の中心周波数（近似）

f0 ≈ 12π√C1C2R2(RV2+R4)

等価インダクタンス Leq ≈ C2 × R2 × (RV2 + R4) をLC共振式に代入した近似です。(RV2 + R4) ≫ R2 かつ低周波近似が成り立つ場合の目安で、実際のEQのピーク・ディップ周波数とは一致しないことがあります。RV2 はRV2の有効抵抗です。R4はRV2の3番端子とグランドの間に直列接続されています。

計算式・疑似インダクタの近似

下段のオペアンプを理想電圧フォロワとすると、C1下端から下段を見た入力インピーダンスは、
Zg(s) = R2(1 + sC2(RV2+R4))1 + sC2R2、s = j2πf です。

低周波での近似：Zg(s) ≈ R2 + sLeq、Leq = C2 × R2 × (RV2 + R4 − R2)。
(RV2 + R4) ≫ R2 なら Leq ≈ C2 × R2 × (RV2 + R4)（単位：H）。この近似は 2πf C2 R2 ≪ 1 の範囲に限ります。

上段も含めたグラフは近似Lではなく、回路の複素節点方程式を各周波数で解き、G(f) = 20 log₁₀ |Vout/Vin| により求めています。RV1は上端から下端への分割抵抗として扱います。

RV2の1・2番短絡時は、3番端子までの抵抗 RV2 = RV2総抵抗 × (1 − ワイパー位置/100) とします（0%＝1番側、100%＝3番側）。Linearは回転位置に比例、Logは50%位置で1番端子からの抵抗が約10%となるオーディオカーブです。

使い方・説明書

疑似インダクタ回路シュミレーターは、オペアンプを使用したジャイレータ／アクティブイコライザー回路の周波数特性を確認するためのツールです。

使用環境：PCのブラウザで御使用ください。インストール不要で、オフラインでも動作します。

基本操作

  1. R・C・RVの数値欄に部品の値を入力します。
  2. 抵抗は Ω、kΩ、MΩ、コンデンサは pF、nF、µF から単位を選択します。
  3. RV1・RV2のスライダーを動かし、0%〜100%の位置を調整します。
  4. 各RV名の下で Linear または Log を選択します。
  5. 変更に応じてグラフと計算結果が自動更新されます。グラフにカーソルを合わせると周波数（Hz／kHz）とゲイン（dB）を確認できます。

RV1・RV2のカーブ

Linear：スライダーの位置に比例して抵抗比が変わります。50%で1番端子からワイパーまでの抵抗が全体の50%になります。

Log：オーディオ用対数カーブの近似です。

Logカーブは市販品の実測特性を厳密に再現するものではありません。

周波数特性の読み方

横軸は20 Hz〜20 kHzの対数周波数目盛り、縦軸はVout/Vinのゲイン（dB）です。0 dBは入出力の振幅が等しい状態、プラスは増幅、マイナスは減衰を示します。

計算結果には、表示範囲内の最大ゲイン・最小ゲインと、その周波数を表示します。RV2を動かすとピークやディップの位置が変化する様子を確認できます。

中心周波数の計算式

LC共振回路の基本式：

f0 = 12π√LC

疑似インダクタの低周波近似（RV2,effはRV2の有効抵抗）：

Leq = C2 R2 (RV2,eff + R4 − R2)

RV2,eff + R4 ≫ R2 の場合、中心周波数の目安は次のとおりです。

f0 ≈ 12π√C1C2R2(RV2,eff + R4)

これは近似式であり、グラフのピーク・ディップ周波数と必ずしも一致しません。周波数特性グラフは回路全体の理想オペアンプ交流解析から計算しています。

使用上の注意

  • 理想オペアンプの小信号モデルです。実機の電源電圧、帯域、飽和、バイアス、部品誤差などは反映していません。
  • 部品値には0より大きい数値を入力してください。
  • グラフと最大・最小ゲインの検索範囲は20 Hz〜20 kHzです。
  • 設定の保存・読み込み機能はありません。
